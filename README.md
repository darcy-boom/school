# CAU SIGNAL｜中国农业大学信息雷达

一个基于公开来源的静态信息聚合网页，整理中国农业大学的重要通知、热点、活动、竞赛和校园服务。

## 打开预览

直接双击 `index.html` 即可离线预览。页面没有构建步骤，也不依赖外部字体或 JavaScript 库。

如果浏览器对本地文件有额外限制，可在本目录启动任意静态文件服务器后打开首页。

## 文件说明

- `index.html`：页面结构
- `styles.css`：高级黑白视觉与响应式样式
- `app.js`：检索、筛选、排序、倒计时和详情交互
- `data/items.js`：页面实际展示的数据与渠道审计
- `data/source-ledger.md`：来源、核验结论和限制台账
- `docs/spec/cau-info-hub-spec.md`：产品与准确性规格
- `docs/superpowers/plans/2026-08-23-cau-information-hub.md`：实施计划
- `.agents/skills/`：仅属于本项目的四个技能副本

## 更新规则

1. 先在 `data/source-ledger.md` 登记原始来源、发布日期、关键节点和限制。
2. 信息至少达到“官方原文”或“官方索引”后，才写入 `data/items.js`。
3. 社交平台内容只作线索和热度旁证，涉及资格、时间和提交要求时必须回查责任单位原文。
4. 校园集市不复制个人联系方式、具体商品和瞬时价格。
5. 每次更新同步修改 `snapshot`、页面核验日期和完整性说明。

## 重要声明

这是截至 2026 年 9 月 6 日 12:39（Asia/Shanghai）的公开信息核验快照，不是中国农业大学官方网站，也不覆盖校内登录态、个人推送和私域群聊。报名、选课、推免与资格认定以原始通知和本人校内系统为最终依据。
