# 中国农业大学信息聚合站：产品规格

## 1. 目标

制作一个面向中国农业大学学生与校园关注者的公开信息快照页，集中呈现重要通知、热点消息、活动安排、竞赛节点和校园服务信息。页面以 2026-08-23 为核验截点，强调可追溯、可筛选、可复核，不宣称覆盖校内登录态、私域群聊或未被公开索引的全部内容。

## 2. 界面类型

- 主要类型：Explore（内容探索）
- 次要类型：Monitor（截止日期与来源状态监控）
- 设计原则：检索、筛选、时间、适用人群和核验状态优先；不使用营销式大幅 Hero。

## 3. 信息范围

- 时间范围：优先收录 2026 年 7 月以来发布、在 2026-08-23 之后仍可行动或仍有解释价值的信息。
- 主题范围：重要通知、校园热点、活动、竞赛、校园服务。
- 渠道范围：中国农业大学官网及院系站、微信公众号与微信视频号公开镜像、公开搜索结果、微博、知乎、小红书、校园集市。
- 不纳入：无法定位原文的传言、仅有截图无出处的信息、私域联系人和校园集市个人联系方式。

## 4. 核验规则

1. 官方原文：校级或院系官方网页可确认标题、日期和主要内容。
2. 双源复核：官方页面与另一独立媒体、或两个职责不同的官方页面相互印证。
3. 官方索引：只能确认标题与发布日期，正文不可公开稳定访问；内容摘要不得超出索引信息。
4. 渠道受限：账号或渠道存在，但登录、robots 或公开索引限制阻止逐条核验；页面必须显式提示。
5. 日期冲突：同时展示页面发布日期和正文落款，不替来源擅自消除差异。

## 5. 卡片字段

- `title`：事项标题
- `category`：通知 / 热点 / 活动 / 竞赛 / 校园
- `publishedAt`：发布日期
- `startAt`、`endAt` 或 `deadline`：发生时间或截止时间
- `audience`：适用人群
- `background`：事项背景
- `summary`：提炼内容
- `action`：读者下一步
- `verification`：核验等级与说明
- `sources`：来源渠道、来源名称、原文 URL、访问日期
- `caveat`：日期冲突、登录限制、知识产权等风险提示

## 6. 交互需求

- 全文检索标题、摘要、适用人群与标签。
- 按分类、核验等级和时间状态筛选。
- 默认按下一关键日期升序排列；无未来日期的热点按发布日期倒序。
- 卡片打开详情抽屉，完整呈现时间、背景、内容、行动和来源。
- “渠道审计”面板逐项说明微信、Google、百度、知乎、小红书、微博、校园集市的覆盖状态。
- 响应式适配桌面与手机；支持键盘焦点和减少动效偏好。

## 7. 视觉方向

- 高级黑白编辑部 / 数据台风格。
- 以墨黑、纸白和中性灰为唯一色系；状态不依赖颜色表达。
- 细边框、克制阴影、较强排版层级；避免渐变、玻璃拟态、装饰性大标题和过度圆角。
- 使用本地字体栈，离线打开仍保持可读性。

## 8. 准确性声明

“完整性”指本项目定义时间窗、公开可访问渠道和字段结构内的覆盖完整，不等于互联网或校内私域信息的绝对穷尽。涉及报名、选课、推免或资格认定时，用户必须以原始通知和本人校内系统为最终依据。
